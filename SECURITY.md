# Security Policy

## Supported Versions

Von Riegen Arquitectos is a website built with React, Vite, and Vercel.

Security updates are applied to the latest version deployed to production. Older versions and historical deployments are not actively maintained.

## Reporting a Vulnerability

If you discover a potential security vulnerability, please report it privately using GitHub's **Private Vulnerability Reporting** feature.

**Report a vulnerability:**  
https://github.com/andreshf44/von-riegen-arquitectos/security/advisories/new

Please include, when possible:

- A description of the vulnerability.
- Steps to reproduce the issue.
- The potential security impact.
- Any relevant technical details or evidence.

Please do not disclose vulnerabilities publicly before they have been reviewed and addressed.

## Security Practices

This project uses security measures including:

- GitHub Dependabot alerts and security updates.
- CodeQL security analysis.
- GitHub secret scanning and push protection.
- Environment variables for sensitive credentials.
- Server-side validation of contact form submissions.
- Rate limiting for the contact form.

Security reports will be reviewed and prioritized according to their potential impact.

## Scope

This policy applies to the source code and website infrastructure maintained in this repository.

Third-party services are governed by their respective security policies.
